# Conferir números

1. Para cada arquivo (ou par de arquivos) em EXEMPLOS/ da tela mexida, rode a versão NOVA da conferência
   com o script de _referencia/numeros/ (Node). Não crie scripts de conferência dentro do site.
2. Monte a tabela: arquivo | aba/grupo | antes (NUMEROS.md) | agora | igual?
   Compare quantidade E total de cada aba.
3. Qualquer diferença: pare, mostre os títulos/boletos que mudaram de lugar e explique a causa.
   Não siga até o usuário decidir. Nunca altere o NUMEROS.md para "bater".
4. Diferença combinada de propósito (regra nova pedida pelo usuário): anote em
   _referencia/NUMEROS.md com a data e o motivo.
5. Nunca copie nomes de fornecedor, valores ou códigos para arquivos que vão para o git.
